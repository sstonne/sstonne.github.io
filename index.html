Cube-in-Hand Multi-Camera Calibration

In progress

The robot grasps a multi-face AprilTag cube and moves it through the workspace, so fixed cameras and the wrist camera are all calibrated against one target in the robot base frame at once. Accurate calibration is the base for precise manipulation such as peg-in-hole, and for aligning simulation with the real scene.

0.3 mmcalibration error, held-out validation
ModuLoop: Low-Level Code Generation Using Modular Synthesizer and Closed-Loop Debugger for Robotic Control

Gina Yoon*, Sumin Lee*, Joo Yong Sim†

IEEE Robotics and Automation Letters (RA-L), vol. 10, no. 12, 2025 · presented at ICRA 2026

paper

An LLM synthesizes low-level robot control code module by module and repairs it through a closed-loop debugger. On a real UR3 arm it handles instructions from direct commands to open-ended requests like "I'm hungry, can you put some snacks on a plate?"

My part: simulation environment, LLM-based object recognition, pick-and-place experiments.

LLM-based Robotic Pipetting Automation

Patent filed · KR 10-2025-0024332

A 6-axis manipulator with a custom pipette end-effector that extracts target coordinates in real time and handles precision dispensing and inspection from LLM-processed instructions.
